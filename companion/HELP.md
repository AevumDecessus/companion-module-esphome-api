# ESPHome

## Minimum ESPHome Version

`2026.1` is the minimum required ESPHome version, as that version fully deprecated plaintext password auth in favor of Noise Encryption. Due to this, password auth is no longer enabled in any way, and an encryption key is required for all communications.

## Available commands

- Push Button
- Set Climate mode
- Set Cover position
- Set Fan state
- Send Lock command
- Set Light state
- Set Light brightness
- Set Number state
- Set Select state
- Set Switch state

## Available feedbacks

- Binary Sensor state
- Climate Mode
- Cover Open/Closed
- Fan state
- Light state
- Lock state
- Number state
- Select state
- Sensor state
- Switch state
- Text Sensor value
